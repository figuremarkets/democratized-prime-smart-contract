# Review rules

- Storage layout (`contracts/*/src/storage/**`, `contracts/repo_token_cw20/src/state.rs`): flag any change to a storage key string or stored type that has no matching migration in `src/msg/migrate.rs`. (AGENTS.md › Protected paths)
- Schemas (`contracts/*/schema/**`): flag schema changes without a matching message or doc-comment change; they are generated by `make schema`. (AGENTS.md › Protected paths)
- Public repository: flag comments, docs, or PR description text that contain Shortcut IDs or links, product or future plans, operational or "production" details, or a description of a known defect or exploit condition. (AGENTS.md › Public repository)
